# 시행착오 기록

같은 작업을 하려는 사람이 같은 곳에서 시간을 쓰지 않도록, 안 됐던 것과 그 이유를 적습니다.

"그림" 절은 이전 판(2D 색 블록 밑그림을 타일 단위로 다시 그리는 방식)에서 겪은 것입니다. 지금 그림은 3D 장면 렌더를 양식만 바꿔 만들지만, 모델이 배치를 바꾸거나 지어내는 문제를 다루는 생각은 같습니다.

## 그림

| 해 본 것 | 결과 | 바꾼 것 |
|---|---|---|
| 2배 해상도(0.25 m/px)로 바로 생성 | 원본 크기로 보면 부드러운 일러스트. 확대하면 해상도가 모자람 | 4배(0.125 m/px)로 생성한 뒤 2×2 최빈색으로 줄여 0.25 m 격자에 맞춤 |
| 도로를 진회색 면으로만 칠한 밑그림 | 일부 타일에서 모델이 도로를 강으로 칠함 | 밑그림에 차선 점선을 그려 넣고, 프롬프트에 "절대 물이 아님", 색 검사로 재시도 |
| 모든 건물을 같은 색 상자로 | 주변 시가지가 전부 비슷한 건물로 나옴 | 건물마다 성격(빌라·한옥·타워…)을 정하고 성격별 지붕·벽 색 표와 프롬프트 문장을 따로 둠 |
| 프롬프트에 건물 이름만 적기 | 광화문·경회루가 평범한 기와집으로 나옴 | 재사용 가능한 사진을 두 번째 이미지 입력으로 주고, 그 건물만 따로 그려 합성 |
| 랜드마크를 일반 타일 크기로 그리기 | 작은 문루가 뭉개짐 | 두 배 확대한 창으로 그려 줄여 붙임 |
| 랜드마크 주변을 네모로 통째 교체 | 바탕과 색이 달라 네모가 뜨고, 모델이 도로에 차를 그려 넣어 움직이는 차와 겹침 | 건물·담 자리만 마스크로 교체. 통째 교체가 필요하면 도로는 바탕 유지 + 클래스별 색 맞춤 |
| 확대 창으로 랜드마크를 그릴 때 주변도 같이 쓰기 | 주변에 없는 한옥을 지어냄 | 확대 창에서는 대상 건물 픽셀만 가져옴 |
| 타일을 넓게(수십 px) 섞어 붙이기 | 서로 다르게 그려진 건물이 반투명하게 겹침 | 섞는 띠를 8 px 로 줄이고, 타일 간 차이는 클래스별 평균색 맞춤으로 처리 |
| 개울(선형 수로)을 전부 그리기 | 복개된 구간까지 도심에 물길이 생김 | 궁궐·공원 안의 것만, 터널·지하 태그는 제외 |
| OSM 관계(멀티폴리곤) 건물 무시 | 국립민속박물관·고궁박물관이 통째로 빠짐 | 관계의 바깥 고리도 건물로 넣고, 3D 장면에 없는 큰 건물은 직접 세움 |

## 자동 검사가 잡아 준 것과 못 잡은 것

- 잡은 것: 도로를 물로 칠한 타일, 잔디가 모래색이 된 타일, 없는 연못.
- 못 잡은 것: 지어낸 물체(옥상 물탱크, 담 옆의 통, 잔디 위 정자), 겹침 자리의 반투명 흔적, 뭉개진 작은 건물. 이런 것은 원본 크기로 잘라 눈으로 봐야 보입니다.
- 색 기준에 걸렸지만 눈으로는 멀쩡한 타일도 있었습니다. 검사는 "다시 볼 곳"을 고르는 용도로 씁니다.

## 참조 사진

- 검색 결과의 순서는 실행할 때마다 달라집니다. "몇 번째 사진"으로 기록하면 다음 실행에서 다른 사진을 가리킵니다. 고른 사진은 제목·주소·해시로 기록하고, 다시 받아 해시를 대조하세요.
- 위키미디어는 원본 크기 요청을 연달아 보내면 429 를 냅니다. 표준 축소본 크기를 쓰고 요청 사이를 띄웁니다.
- 라이선스 필터는 받기 전에 겁니다. 받은 뒤 거르면 쓰면 안 되는 사진이 작업 폴더에 섞입니다.

## 뷰어

- 스프라이트 셰이더의 대입문 몇 줄이 편집 중 주석 뒤로 붙어 버려, 사람·신호등·그림자가 한동안 전혀 그려지지 않았습니다. 테스트는 전부 통과하고 있었습니다(셰이더 출력은 테스트하지 않으므로). 화면을 확대해서 "있어야 할 것이 있는지" 세어 보는 확인이 따로 필요합니다.
- 교차로 정체는 교착이 아니라도 오래 보이면 고장처럼 보입니다. 정지 원인별로 세어 보면(빨간불 대기인지, 논리적 대기인지) 고칠 곳이 보입니다.
- 화면 UI 를 숨기고 찍은 영상에는 출처 표기가 빠집니다. 게시글 본문에 적어야 합니다.
- 성능 수치는 실제 기기에서 재기 전에는 쓰지 않았습니다.

## 데이터와 권리

- "공공 데이터"라고 다 같은 조건이 아닙니다. AI 학습용으로만 쓰라는 조건의 항공영상은 공개 결과물의 입력으로 쓰지 않았습니다.
- 모델도 판마다 라이선스가 다릅니다. 처음 쓴 판은 연구용 라이선스라 그림을 전부 버리고 Apache-2.0 판으로 다시 그렸습니다.
