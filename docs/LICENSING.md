# 공개 전 라이선스 점검

이 프로젝트를 공개하기 전에 한 점검을 절차로 적습니다. 법률 자문이 아니고, 한 개인이 각 원천의 페이지를 직접 읽어 판단한 기록입니다.
실제 출처 목록은 [../CREDITS.md](../CREDITS.md)에 있습니다.

## 원칙

1. **브라우저로 나가는 파일을 먼저 적는다.** 그 파일 하나하나에 대해 "무엇으로 만들었나"를 거꾸로 따라갑니다. 저장소 전체가 아니라 배포물이 기준입니다.
2. **조건은 원문 페이지에서 확인한다.** 모델 카드의 태그, 데이터 포털의 유형 표시, 라이선스 본문을 직접 읽고 날짜와 함께 적습니다. 못 읽은 것은 "확인 못 함"으로 남깁니다.
3. **애매하면 쓰지 않는다.** 대체할 수 있는 입력이면 조건이 분명한 쪽으로 바꿉니다.
4. **표시는 항상 보이는 곳에.** 화면 하단에 상시 표시하고, 자세한 내용은 패널과 CREDITS 에 둡니다.

## 원천별로 본 것

| 종류 | 확인한 것 | 판단 |
|---|---|---|
| OpenStreetMap | ODbL 1.0. 표시 문구, 링크 요구 | 사용. 그림·깊이 이미지는 OSMF FAQ 의 "Produced Work" 로 보고 표시만 함. 도로 형상이 들어 있는 장면 데이터 파일은 데이터 자체이므로 ODbL 로 제공 |

| 공공누리 제1유형 자료 | 유형 표시를 자료 페이지에서 확인. 출처 표시 문구 형식, "기관이 후원한 것처럼 보이게 하지 말 것" | 사용. 공공누리 예시 문구 형식으로 표시하고 비보증 문장을 넣음 |

| 참조 사진 | 위키미디어 공용의 파일별 라이선스 | 퍼블릭 도메인·CC0·CC BY 만. CC BY-SA 는 제외(다시 그린 그림에 동일조건이 따라올 수 있음). 사진은 재배포하지 않고 목록만 공개. AI 가 참조한 그림이 2차적 저작물인지는 정해진 바가 없어 모두 표기 |
| 게임 에셋 | — | 처음부터 쓰지 않음. 차·사람·새는 코드로 그림 |

## 남겨 둔 불확실성

- 편집 모델 저장소의 LICENSE 파일 본문은 주소가 404 라 읽지 못했습니다. 카드의 태그와 본문 문장으로만 확인했습니다.
- ODbL 의 Produced Work 해석은 OSMF 의 설명에 따른 것입니다.
- 공공누리 자료를 중간 배포처(다른 사람이 가공해 올린 데이터셋)를 거쳐 받은 경우, 원 저작물의 조건을 따른다고 보고 원 기관을 표시했습니다.

## 따로 공개 저장소를 만든 이유

작업 저장소에는 공개용이 아닌 것(이전 그림 관련 기록, 내부 장비 경로, 쓰지 않기로 한 데이터의 메모)이 이력에 섞여 있습니다.
공개로 전환하면 이력 전체가 열리므로, 점검을 거친 파일만 모아 새 저장소로 냈습니다. 조립은 스크립트로 하고, 내부 경로나 계정 문자열이 남아 있으면 조립이 실패하게 했습니다.

## 다른 프로젝트에서 쓸 체크리스트

- [ ] 배포물의 파일 목록을 적었다
- [ ] 파일마다 입력 원천을 끝까지 따라갔다(모델, 학습·참조에 쓴 이미지 포함)
- [ ] 원천마다 라이선스 원문을 직접 읽고 날짜를 적었다
- [ ] "비상업만", "학습용만", "동일조건", "재배포 금지" 조건이 있는 입력을 걸러냈다
- [ ] 화면에 상시 보이는 출처 표시가 있다
- [ ] 기관이 후원·보증한 것처럼 읽히는 문장이 없다
- [ ] UI 없이 찍은 영상·스크린샷에 붙일 출처 문구를 준비했다
- [ ] 확인하지 못한 것을 적어 두었다
- [ ] 공개 저장소에 내부 경로·계정·비공개 자료가 없다(자동 검사)
