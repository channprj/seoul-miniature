# 공개 전 라이선스 점검

이 프로젝트를 공개하기 전에 한 점검을 절차로 적습니다. 법률 자문이 아니고, 한 개인이 각 원천의 페이지를 직접 읽어 판단한 기록입니다.
실제 출처 목록은 [../CREDITS.md](../CREDITS.md)에 있습니다.

## 원칙

1. **브라우저로 나가는 파일을 먼저 적는다.** 그 파일 하나하나에 대해 "무엇으로 만들었나"를 거꾸로 따라갑니다. 저장소 전체가 아니라 배포물이 기준입니다.
2. **조건은 원문 페이지에서 확인한다.** 모델 카드의 태그, 데이터 포털의 유형 표시, 라이선스 본문을 직접 읽고 날짜와 함께 적습니다. 못 읽은 것은 "확인 못 함"으로 남깁니다.
3. **애매하면 쓰지 않는다.** 대체할 수 있는 입력이면 조건이 분명한 쪽으로 바꿉니다.
4. **표시는 항상 보이는 곳에.** 화면 하단에 상시 표시하고, 자세한 내용은 패널과 CREDITS 에 둡니다.

## 남겨 둔 불확실성

- 편집 모델 저장소의 LICENSE 파일 본문은 주소가 404 라 읽지 못했습니다. 카드의 태그와 본문 문장으로만 확인했습니다.
- ODbL 의 Produced Work 해석은 OSMF 의 설명에 따른 것입니다.
- 공공누리 자료를 중간 배포처(다른 사람이 가공해 올린 데이터셋)를 거쳐 받은 경우, 원 저작물의 조건을 따른다고 보고 원 기관을 표시했습니다.

## 따로 공개 저장소를 만든 이유

작업 저장소에는 공개용이 아닌 것(이전 그림 관련 기록, 내부 장비 경로, 쓰지 않기로 한 데이터의 메모)이 이력에 섞여 있습니다.
공개로 전환하면 이력 전체가 열리므로, 점검을 거친 파일만 모아 새 저장소로 냈습니다. 조립은 스크립트로 하고, 내부 경로나 계정 문자열이 남아 있으면 조립이 실패하게 했습니다.

## 가져다 쓰기 결정 (2026-11-12)

다른 사람이 이 그림과 장면으로 콘텐츠를 만들 수 있게 열기로 하고, 무엇을 어떤 조건으로 낼지 정했습니다. 안내는 [REUSE.md](REUSE.md).

| 결정 | 이유 |
|---|---|
| 그림·타일·영상·스크린샷 = **CC BY 4.0** | 목표가 "가져다 써서 만들기"라서 상업 이용·수정·재배포를 모두 열었습니다. 비상업(NC)을 붙이면 유튜브 수익 영상, 기사, 인디 게임처럼 경계가 애매한 곳에서 쓰는 사람이 망설입니다. 동일조건(SA)을 붙이지 않은 것도 같은 이유입니다. 출처 표시(BY)는 남겼습니다. 원천(OSM, 공공누리, CC BY 데이터)이 출처 표시를 요구하므로 그림을 쓰는 사람도 어차피 원천을 적어야 하고, 그 자리에 이 프로젝트를 함께 적게 하는 것이 자연스럽습니다. 입력 원천 가운데 상업 이용이나 2차적 저작물을 막는 것은 없습니다(OSM ODbL, 공공누리 제1유형, CC BY 4.0, 그림 모델 Apache-2.0) |
| 장면 데이터(`scene.json`, `map.json`)와 Blender 장면 = **ODbL 1.0** | OSM 의 건물 윤곽·도로·수면을 형상 그대로 담은 데이터라 ODbL 의 파생 데이터베이스입니다. 다른 라이선스를 고를 수 없습니다. 이것으로 렌더한 그림은 Produced Work 라 위 CC BY 4.0 으로 낼 수 있습니다 |
| Blender 장면은 저장소가 아니라 **GitHub Releases** | 지도 둘이 합쳐 수백 MB 라 저장소 이력과 Pages 사이트 용량에 넣지 않았습니다 |
| 경복궁 3D 장면(.blend·.glb) = **ODbL 1.0 + 원천 표시** | 형상의 바탕은 OSM(ODbL)이고, 동네 건물 윤곽·높이에 국토교통부 GIS건물통합정보(V-World, 공공누리 제1유형), Overture Maps(ODbL, 내부에 East Asian Buildings CC BY 4.0)를 함께 썼습니다. 셋 다 출처 표시만 요구하고 ODbL 로 다시 내는 것을 막지 않으므로, 장면은 ODbL 1.0 으로 내고 원천 표시를 함께 적게 했습니다([REUSE.md](REUSE.md) 「3D 파일」 문구). 바닥 그림은 이전 판 3D 장면(Blender)의 조명 없는 평색 알베도 렌더에서 보이는 지면 색을 그대로 쓰고, 건물·나무에 가려진 곳은 OSM 도로와 가장 가까운 지면 색으로 채운 것입니다(`pipeline3d/gyeongbokgung/prep_ground.py`). 생성 AI 그림은 한 화소도 들어 있지 않고, 국가유산청 텍스처에서 뽑은 평균색 재질이 남은 화소도 0 개입니다(알베도 렌더의 재질 번호 맵으로 확인) |
| 여의도 3D 장면 = **OSM 만** | 건물·도로·수면·녹지 모두 OSM 이고, 바닥 그림도 OSM 다각형을 직접 그린 것입니다. 국토교통부 자료·Overture·국가유산청 자료는 쓰지 않았습니다 |
| 여의도 .blend = **장면 전체**(랜드마크 포함) | 여의도 장면은 OSM 과 직접 만든 모델만으로 되어 있습니다. 랜드마크는 사진을 눈으로만 보고 만든 모델이라 사진이 파일에 들어 있지 않습니다 |
| 경복궁 .blend = **국가유산청 전각 46건과 광화문 기록을 빼고** | 국가유산청 3D 기록은 공공누리 제1유형이라 재배포 자체가 금지된 것은 아닙니다. 그래도 원본은 기관이 로그인과 이용 신청서로 내려주는 자료이고, 이 프로젝트는 처음부터 원본(FBX·텍스처)과 그 변환 파일을 배포하지 않는다는 원칙으로 작업했습니다. 이 원칙을 지키면서도 장면을 쓸 수 있게, 전각 자리에는 OSM 윤곽과 높이로 만든 대체 모형을 세우고 자리 표시(이름·배치 변환)와 직접 받은 모델을 끼우는 스크립트(`pipeline3d/gyeongbokgung/insert_khs.py`)를 함께 냈습니다 |
| 3D 장면을 `.blend` 와 함께 **`.glb`(glTF 2.0)** 로도 냄, 라이선스는 둘 다 ODbL 1.0 | `.blend` 는 Blender 가 있어야 열리지만 가져다 쓰는 사람 다수는 게임 엔진·웹·다른 3D 도구를 씁니다. 같은 장면을 형식만 바꾼 것이라 담긴 데이터(OSM 형상)도 라이선스도 같습니다. 툰 명암 같은 노드 재질은 glTF 로 옮겨지지 않아 재질은 근사라고 문서에 적었습니다 |
| 여의도 **랜드마크 GLB**(건물 하나에 파일 하나)도 ODbL 1.0 | 랜드마크 모델은 OSM 의 건물 윤곽·높이를 바탕으로 세우고, 사진을 눈으로 보고 층·띠·첨탑·재질을 덧붙인 것입니다. 윤곽과 높이가 OSM 에서 왔으니 장면 데이터와 같은 원칙으로 OSM 파생 데이터로 보고 ODbL 을 붙였습니다. 덧붙인 모델링(직접 만든 부분)만 떼어 다른 라이선스를 주면 어디까지가 OSM 인지 쓰는 사람이 가려야 해서, 파일 단위로 한 라이선스를 택했습니다. 사진은 파일에 들어 있지 않습니다. 실제 건물 생김새의 권리는 이 라이선스와 별개라 [REUSE.md](REUSE.md) 「주의」에 3D 프린트 상품 같은 판매 목적 복제를 따로 적었습니다 |
| 배경음은 이번 결정에서 뺌 | 생성 모델(ACE-Step 1.5, MIT)의 조건은 CREDITS 에 적어 두었고, 음원 파일에 붙일 라이선스는 따로 정하지 않았습니다 |
| 실제 건물 생김새에 대한 주의를 문서에 둠 | 이 프로젝트가 줄 수 있는 것은 자기가 만든 부분의 권리뿐입니다. 저작권법 제35조 제2항의 판매 목적 복제 예외처럼 굿즈에서 문제가 될 수 있는 부분은 쓰는 사람이 따로 확인하도록 적었습니다 |

.blend·.glb 를 낼 때 확인한 것: 파일 안의 그림은 모두 파일에 넣었고(pack) 경로는 상대 경로로 바꿨습니다. 압축을 푼 바이트에서 작업 장비 경로·장비 이름·계정 이름·국가유산청 캐시 경로를 찾아 0 건인지 봤습니다. `.glb` 는 JSON 부분 전체(그림 `uri`·이름·`extras` 포함)에서 같은 문자열을 찾았고, 그림은 모두 GLB 안에 들어 있어 바깥 경로를 가리키지 않습니다. 참조 사진이나 이미지 평면은 장면에 넣은 적이 없습니다. 다시 열어 렌더한 타일을 공개판 조건 렌더와 비교했고, `.glb` 는 Blender 로 다시 불러와 렌더해 모양과 색을 봤습니다(수치는 릴리스 설명).

## 다른 프로젝트에서 쓸 체크리스트

- [ ] 배포물의 파일 목록을 적었다
- [ ] 파일마다 입력 원천을 끝까지 따라갔다(모델, 학습·참조에 쓴 이미지 포함)
- [ ] 원천마다 라이선스 원문을 직접 읽고 날짜를 적었다
- [ ] "비상업만", "학습용만", "동일조건", "재배포 금지" 조건이 있는 입력을 걸러냈다
- [ ] 화면에 상시 보이는 출처 표시가 있다
- [ ] 기관이 후원·보증한 것처럼 읽히는 문장이 없다
- [ ] UI 없이 찍은 영상·스크린샷에 붙일 출처 문구를 준비했다
- [ ] 확인하지 못한 것을 적어 두었다
- [ ] 공개 저장소에 내부 경로·계정·비공개 자료가 없다(자동 검사)
